### 工程パターン（3ルート）

| パターン | 割合 | 流れ |
|---|---:|---|
| A | 50% | 原材料 → 切断 → マシニング → 仕掛品 → 検査 → 梱包 → 完成品 → 出荷 |
| B | 30% | 原材料 → 切断 → **旋盤** → 仕掛品 → 検査 → 梱包 → 完成品 → 出荷 |
| C | 20% | 原材料 → 切断 → マシニング/旋盤 → **溶接** → 仕掛品 → 検査 → 梱包 → 完成品 → 出荷 |

### 1日あたりの搬送回数

| 区間 | 回/日 |
|---|---:|

| マシニング/旋盤 → 溶接 | 6 |
| マシニング/旋盤 → 仕掛品 | 24 |
| 溶接 → 仕掛品 | 6 |

| 検査 → 梱包 | **30** |
| 梱包 → 完成品 | **30** |
| 完成品 → 出荷 | **30** |

### 安全基準（8項目）

```
フォークリフト通路の最小幅        3.0m
歩行者通路の最小幅               1.2m
設備と設備の最小距離             2.0m
設備と壁・柱の最小距離           1.0m
非常口の前の確保幅               3.0m
非常口の前の確保奥行             3.0m
溶接エリアと原材料置場の最小距離  5.0m
溶接エリアと完成品置場の最小距離  5.0m
```

**★理由が聞けた項目**

> **溶接エリアと原材料置場を5m離す。火花が飛ぶから。**
> v1 にはこの発想が無かった。「重ならなければいい」までしか考えていなかった。
> **安全は、距離の数字になる。ヒアリングしないと出てこない種類の条件だった。**
> （学習日記 Day 37）

## 2. ヒアリングで変わったこと（v1 → v2）

| | v1（案件票を読んで自分で想像した） | **v2（聞いて決めた）** |
|---|---|---|
| 工場 | 20m × 15m | **50m × 50m** |
| エリア | 6つ（各1） | **10種類・計18台** |
| 固定物 | なし | **受入口・出荷口・非常口4か所・柱16本・電気室** |
| 工程 | 1本 | **3パターン（A 50%／B 30%／C 20%）** |
| 安全基準 | なし（隣接・離隔を各1組） | **8項目（すべて数字）** |
| 評価 | 距離の合計 | **距離 × 1日の搬送回数** |
| 距離 | マンハッタン距離 | 中心間の直線距離 |

### いちばん効いた変更：搬送回数

> 原材料置場 → 切断機は **1日30回**。溶接エリア → 仕掛品置場は **1日6回**。
> **同じ10mでも、30回通る10mと6回通る10mは重さが違う。**
> v1 は全部の距離を平等に足していた。だから「近いほうがいい」しか言えなかった。
> **v2 は「よく通る道を短くする」と言える。**
> **これは現場の感覚とも合う。** 毎日30往復する動線が長いと、それがそのまま負担になる。
> （学習日記 Day 37）
